Knowledge Nebula

A privacy-first app that turns folders of documents into an explorable 3D knowledge graph, with parsing, embeddings, and clustering all running on-device — an air-gapped build ships with a zero-network guarantee. Recent releases make the graph portable: one click exports the corpus as an OpenUSD stage, the scene format Pixar built for film, so a document collection becomes a digital twin that opens in usdview, NVIDIA Omniverse, and Reality Composer Pro.

TypeScript · React · Three.js / WebGL · On-device AI · OpenUSD · Python · Desktop app

code & docs on GitHub →

OpenUSD

Documents export as prims carrying a custom docGraph: schema — topics, entities, and the evidence behind every connection — plus cluster hulls and a detailed⇄summary variant switch. Validated against Pixar's usdchecker, with a Python CLI that re-checks the schema and packages .usdz.

usd-agent

An LLM agent whose tools are USD stage queries: ask why two documents are connected and it answers from the exported file, never from guesswork. Runs against cloud models or a fully local Ollama server.

Benchmarks

Measured, not vibes: ~11 docs/s ingest on the 100-PDF demo corpus, a 2,000-node layout settles in under 6 s, rendering holds 120 Hz through 8,400 edges, and the USD export builds in 19 ms.

proof it leaves the app — one exported .usda file, opened in other people's tools
